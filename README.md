# Mijn Weekkompas V4

## Nieuw in V4
- Vanuit Mijn taken: Vandaag, Kies dag en Bewerk.
- Vanuit niet-ingeplande taken: Kies dag.
- Vanuit elke dag in het weekplan: taak toevoegen.
- Niet-dagelijkse taak dubbel in dezelfde week: waarschuwing met verplichte bevestiging.
- Dubbele uitvoering blijft toegestaan voor bijvoorbeeld een extra grondige poetsbeurt.
- Bij onvoldoende dagcapaciteit: verplichte bevestiging om beschikbare tijd automatisch te verhogen.
- Dagelijkse taken blijven elke dag gegarandeerd.
- V4 gebruikt eigen browseropslag zodat oude foutieve plannen niet worden hergebruikt.

## Uploaden naar GitHub Pages
Upload index.html, README.md en .nojekyll naar de hoofdmap van dezelfde repository. Kies Commit changes op main. Ververs de site daarna met Ctrl+F5.
