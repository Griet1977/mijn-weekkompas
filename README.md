# Mijn Weekkompas V2

Een haalbaar huishouden, afgestemd op mijn week.

## Nieuw
- Compleet vandaag-scherm met taken en tijd
- Klikbaar en volledig weekoverzicht
- Niet-ingeplande taken met namen en totale duur
- Prioriteitsiconen
- Capaciteitsbalk per dag
- Schuifbalken per 15 minuten
- Tab Soms vergeten met 38 suggesties
- Werkelijke tijd registreren bij afronden
- Historiek: geschat versus werkelijk
- Zwart-wit minimalistische vormgeving

## Bestaande GitHub Pages-site bijwerken
1. Exporteer eerst een back-up vanuit je huidige app.
2. Pak de ZIP uit.
3. Open je repository op GitHub.
4. Kies Add file > Upload files.
5. Upload alle bestanden uit deze map en bevestig dat bestaande bestanden vervangen worden.
6. Commit naar main. Pages publiceert de update automatisch.
7. Open de site en ververs hard met Ctrl+F5.

Let op: V2 gebruikt een nieuwe lokale opslagstructuur. Importeer een V1-back-up niet in V2. Je kunt je bestaande taken opnieuw invoeren.
